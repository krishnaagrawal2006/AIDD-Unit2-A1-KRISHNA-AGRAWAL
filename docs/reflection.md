# Reflection: AI Coding Assistant Practicum

For this assignment, I developed a Python project called **Expense Splitter** using Google Colab as my coding environment and Gemini Code Assist as my AI coding assistant. The project calculates total expenses, divides costs equally among participants, displays individual balances, and validates expense entries.

During the development process, I applied all three prompting techniques: Zero-shot, Few-shot, and Chain-of-thought. I used Zero-shot prompting to generate the basic project structure and functions. Few-shot prompting helped me create a consistent expense display format by providing input-output examples. Chain-of-thought prompting was used to analyze edge cases such as negative amounts, zero amounts, unknown payers, and invalid input types.

Gemini Code Assist helped me generate code quickly and understand different programming concepts. It made the development process easier, especially when creating functions and improving the code. However, I learned that AI-generated code should not be accepted blindly. I tested the suggestions in Google Colab, checked the output, and made corrections whenever necessary.

Compared with GitHub Copilot, Gemini Code Assist provided a different coding experience. I found it useful for generating code and explaining programming logic. In a real development team, I would choose an AI coding assistant based on the task, code quality, ease of use, and integration with the development environment.

Overall, this assignment improved my prompt engineering skills and taught me the importance of testing, evaluating, and documenting AI-generated code.
