
## Prompt 3 – Chain-of-thought

**Technique:** Chain-of-thought prompting

**Purpose:** To identify and handle edge cases in expense validation.

**Prompt:** Asked the AI assistant to think step by step about
negative amounts, zero amounts, unknown payers, and invalid
input types.

**Evaluation:** Tested the suggested validation logic against
the edge cases and recorded whether the output was accepted,
edited, or rejected.
